# Admin Platform P1 Implementation

## Phase 1

- Media Library: implementing admin media management center.
- Security Center: implementing session and device control.
- Custom Roles: planned after media/security foundations.
- Editorial Calendar: planned after content workflow APIs.
- Revision History: planned after article version service.
- Lead CRM: planned after lead ownership workflow.

## Principles

- Backend permission checks are authoritative.
- Frontend visibility follows effective permissions.
- Existing RBAC roles remain compatible.
- No direct changes to production main until validation passes.
